## Areas of work

- **Complex system and integration QA:** end-to-end behavior across services, APIs, databases, Linux and Windows.
- **Cybersecurity and data security testing:** authentication, authorization, access rules and cross-component interactions.
- **Evidence-driven quality engineering:** risk-based test planning, technical troubleshooting, logs and reproducible bug reports.
- **QA leadership and collaboration:** systematic investigation, clear communication and practical quality processes.
- **AI-assisted QA workflows:** using AI tools where they help, with independent verification of results rather than treating generated output as proof.
