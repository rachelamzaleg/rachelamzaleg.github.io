# Working with Claude in QA

Practical notes from my day-to-day work in Senior System QA and Quality Engineering.

The site focuses on ways I use Claude to make QA work more reusable and consistent, including:

- turning working setups into reusable runbooks
- turning repeated QA work into skills and checklists
- keeping rules, references and project notes separate
- using focused Claude roles for drafting, validation and documentation
